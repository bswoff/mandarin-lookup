# mandarin-lookup

A localhost browser for looking up definitions and usage patterns for Chinese characters and words. Search is powered by CC-CEDICT; definition pages are generated by Claude.

## Running locally

**Backend** (terminal 1, from `backend/`):
```bash
source "$HOME/.cargo/env"
cargo run
```

**Frontend** (terminal 2, from `frontend/`):
```bash
npm run dev
```

Then open http://localhost:5173. Logs are written to `backend/mandarin.log`.

## Environment

Copy `.env.example` to `backend/.env` and add your Anthropic API key (used for definition pages):
```
ANTHROPIC_API_KEY=sk-ant-...
```

The CC-CEDICT dictionary file is bundled at `backend/data/cedict.txt` and loaded at startup. To use a different version, set `CEDICT_PATH` in the environment.

## Clearing the definition cache

To wipe all cached definitions (forces fresh LLM generation on next visit):
```bash
sqlite3 backend/mandarin.db "DELETE FROM definitions;"
```

Individual entries can also be regenerated in-app via the **Regenerate** button on any definition page.
